# HomeIce app

```bash
npm install
npm run dev      # Vite
npm run build    # → dist/
npm run preview
npm run sync     # build + cap sync android
npm run android:build
```

- Web: `dist/`
- Android project: `android/` (appId `com.robertraimondi.homeice`)
- Curriculum data: `src/data/exercises.ts`, `src/data/workouts.ts`, `src/lib/planner.ts`
